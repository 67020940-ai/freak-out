# 🛠️ AI Agent Skills Cheat Sheet & Guide
> บันทึกคู่มือการใช้งานชุด Skills (Superpowers + Matt Pocock + 9arm Skills) สำหรับโปรเจกต์ `freak-out` และ `BUU Take A Leave`

---

## 🚀 Recipes แนะนำตามขั้นตอนการทำงาน

### 🎨 สำหรับโปรเจกต์ `freak-out` (เน้น UX/UI สดใส, สนุก, กวนๆ, Motion & Mascot)
1. **ไอเดีย & ฟีเจอร์ใหม่:** `/brainstorming` ➔ เจาะลึกความคุ้มค่าด้วย `/grill-me`
2. **ออกแบบ UI/UX:** `hallmark redesign <file>` (ปรับให้ไม่ดูเป็น AI Slop)
3. **ทดสอบแอนิเมชัน/ลูกเล่น:** `/prototype` (ลอง Motion & Confetti ก่อนลงโค้ดจริง)
4. **ตรวจทานโค้ดก่อนรวม:** `/scrutinize` (ให้มุมมองบุคคลที่สามวิจารณ์ว่าโค้ดรกไหม)

### 📋 สำหรับโปรเจกต์ `BUU Take A Leave` (เน้น Workflow นิ่ง, ฟอร์มกรอกง่าย, Database เป๊ะ)
1. **วิเคราะห์โมเดลระบบ:** `/domain-modeling` (กำหนดบทบาทนิสิต/อาจารย์, ประเภทการลา)
2. **ซักฟอกเค้นเงื่อนไขระบบ:** `/grill-me` (หาช่องโหว่ เช่น ลาย้อนหลัง, แนบไฟล์แพทย์, การอนุมัติข้ามสาย)
3. **จัดระเบียบหน้า Portal/Dashboard:** `hallmark redesign <file>` (ทำให้หน้าฟอร์มดูโปร คลีน สบายตา)
4. **ลงโค้ดระบบหลังบ้าน:** `/tdd` (เขียนเทสต์ฟังก์ชันการคำนวณวันลาและการบันทึกข้อมูลก่อน)

## 📚 หมวดหมู่คำสั่งและวิธีเรียกใช้งาน

### 1. 🎨 หมวด UI / UX Design & สร้างสรรค์หน้าตาเว็บ

#### 🌟 `hallmark` (สุดยอดเครื่องมือ Anti-AI-Slop)
ป้องกันไม่ให้หน้าเว็บออกมาดูโหล เหมือนใช้ template ทั่วไป ออกแบบตามทฤษฎีดีไซน์ยุคใหม่
* **วิธีใช้:**
  * `hallmark redesign src/components/Header.tsx` : ปรับดีไซน์ส่วนนั้นใหม่ให้มีเอกลักษณ์และโมเดิร์น
  * `hallmark audit src/App.tsx` : ให้ AI ตรวจและให้คะแนนว่า UI ส่วนไหนเชย มีจุดบกพร่องตรงไหน
  * `hallmark study https://example.com` หรือใส่รูปแคปหน้าจอ : แกะรหัสสีและ DNA หน้าเว็บที่เราชอบมาประยุกต์ใช้

#### 🧪 `prototype`
* **วิธีใช้:** พิมพ์ `/prototype` หรือบอก *"ช่วย prototype หน้าจอเลือกชุดให้ mascot ก้อนเมฆหน่อย"* เพื่อทำ interactive UI ชั่วคราวมาลองกดเล่นก่อน

#### 🖼️ `canva` (MCP Tool)
* **วิธีใช้:** บอก AI ให้ *"ใช้ Canva MCP ช่วยสร้างดีไซน์แบนเนอร์/ภาพโปสเตอร์..."* เพื่อดึง asset ภาพเข้าโปรเจกต์

### 2. 💡 หมวดคิดค้นฟีเจอร์ & Brainstorming

#### 🧠 `/brainstorming`
* **วิธีใช้:** พิมพ์ `/brainstorming` เมื่อมีไอเดียคร่าวๆ เช่น *"อยากเพิ่มระบบ Streak สะสมวันเข้าเรียน"* AI จะช่วยพาคิด User Flow และทางเลือกต่างๆ

#### 🔥 `/grilling` หรือ `/grill-me`
* **วิธีใช้:** พิมพ์ `/grill-me` หรือ *"ช่วย grill ฟีเจอร์นี้หน่อย"*
* AI จะสวมบทบาทผู้ซักฟอก ถามคำถามยากๆ ต้อนให้เราคิดถึง Edge Cases ทุกด้านจนไอเดียตกผลึก

---

### 3. 🏗️ หมวดสถาปัตยกรรมโค้ด & การพัฒนา (Engineering)

#### 📐 `/domain-modeling`
* **วิธีใช้:** พิมพ์ `/domain-modeling` เพื่อเขียนหรืออัปเดต `CONTEXT.md` กำหนดคำศัพท์เฉพาะในระบบ (เช่น LeaveRequest, Quota, Approver)

#### 🧩 `/codebase-design`
* **วิธีใช้:** พิมพ์ `/codebase-design` ใช้เมื่อต้องการออกแบบ Interface ของ Service/Module ให้ไม่ผูกติดกัน (Loose coupling, Deep modules)

#### 🎫 `/to-tickets` & `/to-spec`
* **วิธีใช้:** พิมพ์ `/to-spec` หรือ `/to-tickets` เพื่อเปลี่ยนข้อสรุปจากการ Brainstorm เป็น GitHub Issues อัตโนมัติ (อ่านตามที่ตั้งไว้ใน `docs/agents/issue-tracker.md`)

#### 🔴🟢 `/tdd` (Test-Driven Development)
* **วิธีใช้:** พิมพ์ `/tdd` เมื่อจะเพิ่มฟังก์ชันที่มีตรรกะซับซ้อน AI จะช่วยเขียน Test ให้ Fail ก่อน ➔ เขียนโค้ดจริง ➔ Refactor

---

### 4. 🛡️ หมวดตรวจเช็คคุณภาพ, คุมสติ & แก้บั๊ก (9arm Skills)

#### 🧐 `/scrutinize`
* **วิธีใช้:** พิมพ์ `/scrutinize` เมื่อเขียนฟีเจอร์เสร็จหรือกำลังจะทำ PR
* AI จะอ่านทั้งโค้ดและตั้งคำถามว่า *"ทำไมต้องแก้ตรงนี้? มีวิธีที่ง่ายกว่าและตรงจุดกว่านี้ไหม?"*

#### 🩺 `/debug-mantra`
* **วิธีใช้:** พิมพ์ `/debug-mantra` เมื่อเจอ Error, หน้าจอพัง, หรือโค้ดไม่ทำงานตามคาด
* บังคับให้เริ่มด้วยวินัย 4 ข้อ:
  1. Reproduce (ทำให้บั๊กเกิดขึ้นซ้ำให้ได้)
  2. Trace fail path (ไล่เส้นทางที่พังจากต้นสาย)
  3. Falsify hypothesis (ทดสอบหักล้างสมมติฐาน)
  4. Cross-reference (ตรวจเช็คทุกหลักฐานที่เกี่ยวข้อง)

#### 👔 `/management-talk`
* **วิธีใช้:** พิมพ์ `/management-talk` หรือบอก *"ช่วยแปลงสรุปนี้ให้ส่งอาจารย์/หัวหน้าทีมหน่อย"*
* แปลงภาษา Technical ยั้วเยี้ย ให้กลายเป็น Executive Summary ภาษาทางการ อ่านง่าย ชัดเจน

#### 📝 `/post-mortem`
* **วิธีใช้:** พิมพ์ `/post-mortem` หลังแก้บั๊กใหญ่สำเร็จ เพื่อบันทึก Root Cause, วิธีแก้ และวิธีป้องกันไม่ให้เกิดซ้ำ

#### 🤖 `/qwen-agent`
* **วิธีใช้:** พิมพ์ `/qwen-agent` หรือบอก *"ใช้ qwen ทำ..."* สำหรับงานแก้ format, rename หลายๆ ไฟล์, หรืองานซ้ำๆ ที่ไม่ต้องใช้พลังคิดเยอะ

#### 🛑 `/qwenchance`
* **วิธีใช้:** พิมพ์ `/qwenchance` เมื่อรู้สึกว่า AI เริ่มคุยวนไปวนมา หรือกำลังจะติดลูป เพื่อตัดวงจรและดึงกลับเข้าประเด็นหลัก
